# Maritime Cabs — public website

Static public landing page for Maritime Cabs (passenger-facing taxi-booking platform, New Brunswick,
Canada). Deployed via GitHub Pages.

Source of truth for this content lives in the main app repository at `website/` — copy any edits there and
re-copy here (or redeploy via that repo's `npm run deploy:website` style step, if one is added later) rather
than editing this repo directly, so the two never drift.

No build step: plain HTML/CSS, no framework, no dependencies.
